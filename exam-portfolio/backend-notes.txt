1. What is backend development?
   Backend development refers to the 'server-side' of an application. It focuses on databases, scripting, and the application's core logic and functionality.

2. Give 2 examples of backend frameworks.
   Examples include: Django (Python) and Express.js (Node.js).
3. What is an API?
   An **API** (Application Programming Interface) is a set of rules and protocols that allows different software applications to communicate with each other. It acts as a middleman between the client (frontend) and the server (backend).
